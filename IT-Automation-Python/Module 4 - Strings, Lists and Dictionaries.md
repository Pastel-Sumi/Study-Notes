**String indexing** lets us access a specific element/letter of a string.
* **Slice:** The portion of a string that can contain more than one character; Also sometimes called a substring.
* **Method:** A function associated with a specific class.
* `upper(), lower()`
* `strip()` removes spaces, newline characters and tabs.
* `lstrip()` and `rstrip()` removes the spaces from either left or right.
* ""`.join()` to join text with the parameter inside "".
* `.split()` divides the string into each word.
* The method **count** can be used to return the number of times a substring appears in a string.

## Lists
* Sequences of elements of any type, and are mutable.
* `.insert(index, element)`
* `.remove(element)`
* `.pop(index)` removes the element at that index.
* `enumerate(list)` can gives us an index, element when iterating.
* `list.sort()` sorts the items in the list.
* `list.reverse()` reverses the order of items of the list.
* `list.extend(other_list)` Appends all the elements of other_list at the end of list.
