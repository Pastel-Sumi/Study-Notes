* Disk/HDD/Storage/SSD: This is going to store all of our data, persistently. It's measured in hundreds of GigaBytes (GB), even TeraBytes (TB).
	* Byte = 8 bits that can store either 1 or 0.

* Memory/RAM (Random Access Memory): Used for storing information, smaller than disks. It's cheaper in resources for writing data than disks. Faster reading and writing than disks.

* CPU(Central Process Unit): Writing/Reading information to RAM or Disk. The CPU is going to execute code
	* Cache: Component of the CPU that its used to speed up writing/reading (scale of ns). Mainly used as a sustitution for the RAM. The CPU takes portions of the RAM that we were writing/reading frequently and have it on the Cache.

The downsides of both RAM and Cache is that it's not persistent memory.
