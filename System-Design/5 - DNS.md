**Domain Name System**. 
* We don't want to type the IP of a website (for example google) in our browser.
* We want to have a way to contact websites, that's where the **DNS** comes into play.
* We send the name of the domain to the DNS and this returns the IP of said website, this way we can connect to the wanted site.
* In other words, our computer can translate the domain of the site into an IP address..

* **ISP (Internet Service Provider)** plays a big role in this too. Your ISP interacts with other services
* **ICANN (Internet Corporation for Assign Names and Numbers)**, basically the owners of all the domain names.
* **Domain Registrars** resell the domains.

The **DNS record** basically stores information about resolving a DNS request.

* **Dynamic DNS** are a thing, which means that static IP adresses are not necessary.

We don't have to go through the same request every time we access the same site. We already have the IP stored in our computer, this is an example of **Caching**.
